# 🤝 Contributing to Bakwaas

Bakwaas karo, contribute bhi karo!

## How to Contribute

1. Fork the repo
2. Create a branch: `git checkout -b feature/your-feature`
3. Make your changes
4. Commit: `git commit -m "feat: your change"`
5. Push and open a Pull Request

## Areas Where Help is Needed

- Better Hinglish model fine-tuning
- Native Swift/SwiftUI menu bar app
- Windows/Linux port
- Streaming real-time transcription
- iOS companion app

## Code Style

- Python: follow PEP8
- Comments in English or Hinglish — both are fine
- Keep it simple, keep it local-first
